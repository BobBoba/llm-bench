Собери CLI-утилиту в `index.ts` (запуск `bun run index.ts <file>`): по умолчанию печатает число строк, слов и байт файла-аргумента (три числа). Флаг `--lines` печатает только число строк, `--words` - только число слов. Перед началом работы выполни `bun install`, чтобы подтянуть `typescript`/`bun-types` из `package.json`. Проверь сам через `bunx tsc --noEmit --strict` и `bun run index.ts` на тестовом файле.
